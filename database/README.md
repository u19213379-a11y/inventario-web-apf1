# Base de datos APF1 → APF2

- **`inventario_apf1.sql`**: versión histórica del primer avance. Conservar como evidencia del diseño original; no volver a ejecutar sobre una BD existente.
- **`inventario_apf2.sql`**: esquema compatible con el APF1 y migración de las dos credenciales académicas de demostración. Hacer backup previo.

El APF2 no cambia el nombre de base `inventario_apf1` ni las tablas `usuarios`, `categorias`, `productos`, `movimientos`.
